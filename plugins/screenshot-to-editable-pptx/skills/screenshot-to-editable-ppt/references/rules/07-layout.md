# 07 — Layout (page / section compositions)

**Category tag:** `layout`  
**When to update:** lopsided balance, weak hierarchy, missing focal point, inconsistent grid/margins, cramped whitespace, mixed icon styles across a layout screenshot.

## Mode

This category applies when the screenshot is a **layout** (full slide, page section, multi-region composition).  
For a tight **component** crop (one nest, one icon, one widget), skip this file and use [01-measure.md](01-measure.md) + nest/internal rules.

**Still measure from the photo.** Layout principles guide *how you read and check* the composition. They do **not** invent margins, columns, or hierarchy that the screenshot does not show.

## Role

Treat every layout screenshot as a **functional, purposeful composition** — clean, high-impact, executive-slide quality — while reconstructing it as native editable PPT.

## Core principles (rebuild lens)

### 1. Balance
- Every element (text block, chart, metric, icon) has **visual weight** from scale, bold, color, or fill.
- Avoid lopsided layouts: heavy mass on one side needs offset (supporting text, diagram, or measured whitespace) on the other.
- Reconstruct the photo’s balance — do not “fix” asymmetry the screenshot intentionally uses.

### 2. Contrast & hierarchy
Typography tiers (match photo scale/weight; measure each tier’s cap-height → pt):
| Tier | Role |
|------|------|
| Headline / core takeaway | Largest, boldest, high contrast |
| Section headings / key metrics | Mid-size, medium-to-bold |
| Body / captions | Smaller, subdued, regular |

Use high contrast text↔background; accent color only where the photo accents critical data.

### 3. Emphasis & focal point
- **One slide, one core idea** — identify the primary focal point (metric, takeaway, architecture block).
- Preserve directional cues (lines, arrows, spatial framing) that lead the eye to that focus.

### 4. Repetition & unity
Across the layout (and deck if multi-slide):
- Fixed margins, gutters, grid — **measure** them; keep siblings consistent.
- Consistent font pairing / weights as in the photo.
- Unified iconography (same stroke language — never mix flat + 3D + sketch unless the photo does).
- Predictable positions for titles, badges, trackers when the photo repeats them.

### 5. Rhythm & movement
- Honor the scan path (top→bottom, left→right, or stepwise numbered cards).
- Uniform spacing inside repeated cards/containers; no erratic scatter.

### 6. Proportion & whitespace
- Whitespace is structure — do not crowd edges or invent fill to “use space.”
- Supporting text must not compete with headlines/metrics; keep measured proportional gaps between hierarchy tiers.

### 7. Variety with restraint
- Full-bleed / single-stat focal slides are allowed when the photo is that pattern.
- Variance stays inside the photo’s palette, grid, and type system.

## Pre-build brief (layout mode only)

Before measuring boxes, state (short):

1. **Core takeaway** — 1 sentence (what the slide is for).
2. **Visual layout architecture** — e.g. 3-column comparison, split 60/40, stepwise horizontal flow, header + two-column body + footer.
3. **Hierarchy & accents** — focal anchor, type tiers, accent color role, whitespace boundaries (from the photo).
4. **Content map** — headline, body, data callouts, icons — with rough regions, then **measure** each region’s pads.

Then run the universal measure procedure on every element.

## Component mode (contrast)

| Layout | Component |
|--------|-----------|
| Columns, gutters, header/footer, page rhythm | Nest pads, badge↔lines, local stroke |
| Hierarchy across the frame | Hierarchy inside one widget |
| Brief steps 1–4 above | Skip brief; measure internals immediately |

## Fail patterns
- Copying another deck’s margins into a new layout screenshot.
- “Centering leftover space” instead of measured pads.
- Flattening hierarchy (all text same pt).
- Mixing icon styles when the photo is unified.
- Ignoring whitespace the photo uses as structure.
